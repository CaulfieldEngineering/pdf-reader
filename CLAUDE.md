# Readalong (pdf-reader): notes for Claude

Electron + TypeScript desktop app that reads PDFs aloud with a local Kokoro voice. Read README.md first.

## Rules

- **Never commit client or confidential documents**, and don't quote them in code, tests or commits. Test PDFs are generated by `tests/fixtures.ts`. `.gitignore` blocks every other PDF.
- **Don't get in Joe's way when testing.** Launch the app with `READALONG_TEST=1` (or `--screenshot=<dir> file.pdf`). In that mode the window is never shown, focused or on top. Run installers with `/S` and uninstall afterwards. Kill any Electron processes you started.
- **Electron is pinned to 44.x** because Defender removes Electron 45.2.3's `ffmpeg.dll` on this PC (see README, Known limitations). Without it the renderer crashes.
- When running Electron from a VS Code terminal, unset `ELECTRON_RUN_AS_NODE` (and `CHROME_CRASHPAD_PIPE_NAME`) first.
- Keep detectors conservative. A wrong skip hides body text; a missed skip only reads a stray label.

## Checks before committing

`npm run typecheck`, `npm test`, and for UI changes `npm run build` plus a hidden screenshot run.
